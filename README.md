#### ✅ المرحلة الأولى: الأساسيات (Python و Git)

لازم نتأكد إن "لغة البرمجة" (بايثون) نفسها موجودة.

1. **تسطيب بايثون (Python):**
    
    - روح على [python.org](https://www.python.org/downloads/) ونزّل آخر نسخة (زي 3.11 أو 3.12).
        
    - **(مهم جداً ⚠️):** وإنت بتسطب، علّم (Check) على المربع اللي بيقول: `Add Python to PATH`. دي أهم خطوة.
        
    - عشان تتأكد إنه اتسطب، افتح ترمينال (PowerShell) جديد واكتب:
        
        PowerShell
        
        ```
        python --version
        ```
        
        (لو طلعلك رقم، يبقى إنت تمام).
        
2. **تسطيب Git:**
    
    - ده عشان الـ `git clone` وأي تعامل مع الكود في المستقبل.
        
    - روح على [git-scm.com](https://www.google.com/search?q=https://git-scm.com/downloads) ونزّله وسطّبه (دوس Next على كل حاجة).
        

---

#### ✅ المرحلة الثانية: أدوات بايثون (pip و uv)

دلوقتي هنسطب "الأدوات" اللي بنجيب بيها الـ packages (زي LangGraph).

1. **التأكد من `pip`:**
    
    - `pip` هو "مدير الحزم" بتاع بايثون (بييجي معاه). اتأكد إنه موجود:
        
        PowerShell
        
        ```
        pip --version
        ```
        
2. **تسطيب `uv` (الأداة السريعة):**
    
    - دي الأداة الجديدة اللي LangGraph بيحبها عشان سريعة. هنسطبها مرة واحدة بس على الجهاز كله:
        
        PowerShell
        
        ```
        pip install uv
        ```
        

---

#### ✅ المرحلة الثالثة: تسطيب الـ LangGraph CLI

دي الأداة اللي فيها الأمر `langgraph new` اللي إنت عايزه.

1. **تسطيب `langgraph-cli`:**
    
    - برضه هنسطبها مرة واحدة بس على الجهاز كله:
        
        PowerShell
        
        ```
        pip install langgraph-cli
        ```
        
2. **التأكد من `langgraph`:**
    
    - عشان تتأكد إن الأمر اشتغل، اكتب:
        
        PowerShell
        
        ```
        langgraph --version
        ```
        
        (لو طلعلك رقم، يبقى ألف مبروك، الجهاز جاهز).
        

---

#### ✅ المرحلة الرابعة: تشغيل الأمر بتاعك

دلوقتي أي حد في فريقك يقدر يشغل الأمر بتاعك في أي مكان.

1. **اختار مكان** (مثلاً على الـ Desktop أو في فولدر المشاريع).
    
2. **شغّل الأمر:**
    
    PowerShell
    
    ```
    langgraph new acip-red-team-agent
    ```
    

---

### ⚠️ أهم خطوة: "إيه اللي نعمله بعد `langgraph new`؟"

دي الخطوات اللي فريقك هيعملها **بعد** ما الأمر اللي فوق يخلص، عشان يشغلوا المشروع المتكامل (بالـ HTML والسيرفر) اللي إحنا عملناه:

1. **ادخل الفولدر:**
    
    PowerShell
    
    ```
    cd acip-red-team-agent
    ```
    
2. اعمل Sync للبيئة (بـ uv):
    
    الأمر ده بيقرأ pyproject.toml، وبيعمل البيئة (.venv) وبيسطب جواه كل حاجة (LangGraph, LangChain).
    
    PowerShell
    
    ```
    uv sync
    ```
    
3. **شغّل البيئة:**
    
    PowerShell
    
    ```
    .\.venv\Scripts\activate
    ```
    
    _(لازم تشوف اسم البيئة ظهر في أول السطر)_
